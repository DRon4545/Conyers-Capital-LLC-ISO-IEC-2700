## Corrective-action methodology

For each finding:

### 1. Correction
Address the immediate condition.

### 2. Root-cause analysis
Determine why the condition occurred. Suggested methods include:

- 5 Whys
- process analysis
- people/process/technology review
- control-design analysis

### 3. Corrective action
Change the system or process so recurrence is less likely.

### 4. Evidence
Attach objective evidence showing implementation.

### 5. Effectiveness review
Verify that the corrective action works over an appropriate period.

### 6. Closure
Only close the finding when the auditor or authorized reviewer has sufficient objective evidence.

## Example root-cause analysis — NC-05

**Problem:** Internal-audit activity was planned but not adequately evidenced.

**Potential root cause:** Audit responsibility was assigned as an administrative task rather than embedded in an annual risk-based audit program with independence, working-paper, and closure requirements.

**Corrective action:** Create an annual audit program, risk-rank audit subjects, assign an objective auditor, define audit criteria, retain working papers, and track corrective actions through closure.

**Effectiveness test:** Review the next completed audit cycle and verify that the program, evidence, findings, and closure process operate as designed.
